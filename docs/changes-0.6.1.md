# ReShiki 0.6.1

**Chemical drawing, reinvented.**

ReShiki 0.6.1 adopts the rust Reaction Cycle identity across the application and website. The open molecular ring ends in a reaction arrow, representing iteration and transformation.

- The desktop toolbar and About window use the new symbol. macOS bundles and Windows applications and installers include native app icons.
- The repository includes light and dark logo variants, wordmarks, promotional cards, and icon exports, with a usage guide and reproducible export script in `assets/branding/`.
- The homepage includes the 83-second promotional video, with playback controls, English captions, a poster, and a download link. It also displays the latest published release.
- The homepage and promotional artwork use the tagline “Chemical drawing, reinvented.”

This release includes the drawing improvements and native offline chemistry described in the [0.6 release notes](changes-0.6.md). It follows an unpublished 0.6.0 release attempt; 0.6.1 uses a new tag so existing tag history is preserved.

Downloads cover Apple Silicon macOS, Windows x64 and ARM64, and Linux x64 and ARM64. The macOS application and disk image are signed and notarized as part of release verification. Python, RDKit, and uv are not needed to run the application.
