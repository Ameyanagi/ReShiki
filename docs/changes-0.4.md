# ReShiki 0.4.0

- Idle windows stop polling inactive assistant, chemistry, and recovery tasks.
- macOS gets a signed, notarized `.dmg` with drag-to-Applications installation.
- Windows x64 and ARM64 get per-user setup programs with shortcuts and uninstall support. Windows builds remain unsigned.
- ReShiki checks for stable updates in the background. Click the app name to check manually, download an update, or disable automatic checks.
- The visual manual has a simpler header, warmer colors, and a direct link to the assistant guide.

Install uv before the first launch. Portable downloads remain available for macOS, Windows, and Linux.
