# Start an empty drawing

ReShiki opens with a blank canvas. New drawings, new tabs, and drawings emptied
by Delete or Undo keep the canvas clear, ready for drawing tools and keyboard
shortcuts.

Use **Open…** to open a drawing, **Paste** to use the clipboard, or the **Add**
panel to insert a template. Use **Import** to insert a chemical name or SMILES.
These commands remain available through the usual application controls.

Dragging a file onto the canvas shows drop feedback while the drag is active.
The existing file checks and open or import behavior still apply. Leaving the
window or finishing the drop clears the feedback.
