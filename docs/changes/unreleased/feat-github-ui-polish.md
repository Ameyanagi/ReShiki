- GitHub drawings show their repository: a colored badge with its initials on
  each tab, the repository in the window title, and a status bar chip such as
  **● lab-notes / scheme · 1 unsent** with **Send**. Right-click a tab to change the
  color. **Send** opens a small box above the chip with the message selected;
  Enter sends. The GitHub button has a dot while anything is not sent, and its
  menu shows what applies now, then your account.
- Sign-in shows the code at once and closes by itself, then goes on with what
  started it. **Open from GitHub…** opens the repository used last, lists
  drawings newest first with who changed them, and makes a new repository,
  drawing or folder in place. Signed out, it shows the repositories known on
  this computer.
- A drawing changed on GitHub is a question, not an error: the status is
  amber, and GitHub's and yours show side by side with the differences
  painted in ReShiki's highlight. **Keep both** also opens GitHub's version.
  **Versions** is now **History**, a clock tab in the inspector that groups
  saves and commits by day.
- The star card and About say what Star does: signed in, **★ Star on GitHub**
  stars ReShiki with your account (**Stars ReShiki on GitHub as @you.**);
  signed out, **★ Star on GitHub ↗** opens GitHub in your browser.
