- Open other people's GitHub repositories by link: paste a github.com link
  into **Open from GitHub…**, the command palette or the window, or choose
  **+ Add public repository…**. Public repositories open signed out too, with
  names only. A repository you may not send to is **Read only**: edit and save
  here, then **Save a copy…** into one of yours. Repositories opened by link
  stay listed, tagged **shared**, until you remove them.
- A link to another branch or a commit opens that version as an **Old
  version** in its own tab; **Open latest** goes to the drawing as it is now.
- Right-click a GitHub tab to **Copy GitHub link**. History, the picker and
  the conflict and compare headers say **You** for your own changes. The
  command palette lists every drawing and repository known on this computer.
