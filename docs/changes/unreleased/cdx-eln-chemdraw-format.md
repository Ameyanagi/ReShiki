- Choose the ChemDraw format ReShiki writes in **Settings → Copy & export → ChemDraw files**: CDXML (the default) or CDX, which electronic lab notebooks usually need. The Export tab gains **CDX drawing** and lists the chosen format first, as does **Save as…**. See [Use ReShiki drawings in an ELN](eln.md).
