- Align commands have one set of names in the right-click menu, the context
  row and the command palette: **Align left**, **Align center**, **Align
  right**, **Align top**, **Align middle** and **Align bottom**. Before, the
  palette called **Align center** "Align middles horizontally". **Flip
  horizontal** and **Flip vertical** are named the same way everywhere.
- In the right-click menu, **Copy** sits with **Cut**, **Copy as** and
  **Paste**. Only **Delete** stays pinned at the bottom.
- Each command has one name on every surface: **Page setup…**,
  **Recalculate** (was Check structure), **Save as .rsk…**, **Abbreviate
  selection…** (was Create group label… and Contract selection), **Save as
  abbreviation**, **3D optimize…**, **Clean up…**, **Atom maps**,
  **Assistant** and **Show/hide side panel**. Menu items use sentence case,
  such as **Convert to wedge drawing**.
- Status messages state the result, such as "3D projection applied", without
  repeating that Undo brings the drawing back. Long messages are shorter.
- The app writes US English (**Center charge in ring**, **Symmetrize**,
  "canceled"), real plurals instead of "(s)", and "Esc" for the Escape key.
