- Commands and shortcuts share one palette. Help, **?** and **F1** open **Keys**; **Search…** and **Cmd/Ctrl+K** open commands. Use **All · Insert · Edit · View · File · Keys** or **Tab** to filter, and see the selected description and before/after example below the list.
- Press **F6** or **Shift+F6** to move between search and the available **Run**, **About**, and **Examples** actions.
