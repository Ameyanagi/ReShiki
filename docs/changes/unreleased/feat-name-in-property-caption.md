- **The name above the properties.** **Show properties** has a **Name** row,
  and **Show chemical name** now shows the same row: the molecule's name in
  bold, with Mol. Wt., Exact Mass or the other properties below it in one
  caption. The automatic name follows structure edits in the same Undo step.
- **Your own name.** Type a name such as `Compound 3a` in the new **Name**
  field of **Molecular properties**, or double-click the name on the canvas.
  ↺ returns to the automatic name. A custom name stays when the structure
  changes, and the panel notes that it changed.
- CDXML and CDX save the name as plain text above the property lines, which
  stay linked for ChemDraw. `.rsk` files with a name line use document
  version 39.
