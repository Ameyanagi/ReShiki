- When someone changes an open drawing on GitHub, the status bar chip shows
  **Newer on GitHub** with **Update** as you come back to the window.
  **Update** shows their drawing in one undo step and says who changed it,
  such as **Updated · @alice: Add an ethyl group**. If you have changed the
  drawing too, the chip shows **Review** instead. See
  [Keep drawings on GitHub](github.md).
