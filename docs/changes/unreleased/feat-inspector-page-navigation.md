- Chemical names and Assistant keep their existing layouts with the inspector tabs visible above them. Their existing Back and Close controls, or Esc outside a text field, return to the preceding page. A new selection returns to Properties.
- Unfinished drawing style and color theme drafts stay intact while visiting Chemical names or Assistant, including through command search. Returning to the editor restores the draft; leaving for another panel or discarding the editor still ends it.
