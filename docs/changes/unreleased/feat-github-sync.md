- The desktop app keeps drawings in your GitHub repositories. A new **GitHub**
  button in the toolbar signs in with a code, opens drawings with **Open from
  GitHub…** and sends them with **Send to GitHub**. **Save** stays on this
  computer; **Send** makes one commit of every changed drawing in the
  repository, with an SVG preview beside each. The status bar shows what is not
  on GitHub yet, closing such a drawing asks **Send to GitHub** or **Later**, and
  **Versions** opens or restores earlier saves and commits. A drawing changed
  on GitHub meanwhile is never overwritten: ReShiki shows GitHub's and yours
  side by side with the differences highlighted, then **Keep GitHub’s**,
  **Keep mine** or **Keep both**. **Versions → Compare with current** shows
  any version beside the drawing now. See
  [Keep drawings on GitHub](github.md) and the
  [privacy policy](privacy-policy.md#github-sign-in-and-send).
- Signed in to GitHub, **Star on GitHub** stars ReShiki with one click, without
  a browser, and the star card never asks someone who already starred.
