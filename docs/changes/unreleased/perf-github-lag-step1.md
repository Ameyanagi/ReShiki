- **Open from GitHub…** feels faster. A folder's files show as soon as it is
  listed, folders first, then by name; who changed each file and its preview
  fill in as they arrive, and no tile moves under the pointer.
- Opening a drawing from the picker reads only the drawing, and nothing at all
  once its preview has loaded. Going back up, into a folder again or choosing
  the same repository again no longer waits for GitHub.
- **Send** uploads several drawings at once, and the status bar chip says
  **Saving…**, then **Sending…**, from the moment you press it.
