- **Open from GitHub…** lists every chemistry file ReShiki opens, not only
  drawings: `.mol`, `.sdf`, `.cdxml`, `.cdx`, `.rxn` and `.smi`, each with its
  format. One opens read only; **Save** makes a `.rsk` copy and leaves the
  file on GitHub as it is.
- **Insert** (Shift+Enter, or right-click a file) puts a file's structures
  into the drawing in front as one Undo step.
- Switch the picker between **Tiles** and **Tree**; it opens in the view you
  used last. The tree lists the whole repository, searches all of it, and
  previews the selected file beside it.
- Folders of more than 200 files show the first 200; the search finds the
  rest.
