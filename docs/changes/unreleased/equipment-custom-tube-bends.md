- Right-click stainless-steel compression tubing to add a bend point. Drag the free side around that point or enter an angle and radius. Release the handle to finish the bend, or press Enter or leave a field to set its value. Each edit updates the cut length and can be undone in one step. Adjust the radius of an existing bend between fixed fittings when the new radius fits.
