- After five exports or copies, on a later day than the first launch,
  the desktop app asks once in a small card at the bottom right of the canvas:
  **Enjoying ReShiki?** It waits until you have not touched the window for 30
  seconds, and never appears while you type in a field, drag, or have a menu,
  panel or dialog open. **Star on GitHub** opens the project page in your
  browser. Without a star, it asks again at most once, in a later feature
  release and at least 90 days later. Nothing is sent anywhere. See the
  [privacy policy](privacy-policy.md#github-star-request).
- In the desktop app, **ReShiki → Check for updates** has a **Star ReShiki on
  GitHub ↗** link after **Release notes ↗**. After you use it, the card no
  longer asks. **Help → About ReShiki** opens the same panel.
