# PDF shading at publication size (#522)

Standalone PDF exports now place 3D shading at the same coordinates as the
drawing. Ball-and-stick models retain shaded spheres and cylinders;
space-filling models retain their highlights. The fix also applies to crystal
models. Drawing size and page-PDF placement are unchanged.

The vendored svg2pdf 0.13.0 exporter already writes the page's DPI transform into
the PDF content stream. Gradient patterns also need that transform in their
coordinate matrices. The change passes the existing transform into paint
accumulation without writing another content transform. Form XObjects keep
local paint coordinates, including the isolated groups used for opacity.

## Validation

The new DPI regression fails on the base at 96 DPI: it reads a pattern matrix
`[1, 0, 0, -1, 0, 80]` where the 90 x 60 point page requires
`[0.75, 0, 0, -0.75, 0, 60]`. All three ordinary regression tests pass after
the fix:

- 72, 96 and 144 DPI: page bounds, linear/radial pattern matrices, nested
  transforms, isolated opacity groups and a single content-scale operation.
- `to_chunk`: unscaled pattern coordinates and the existing unit-sized Form
  XObject placement.
- Ordinary 2D export: its physical dimensions remain unchanged, including the
  22.4 point two-carbon bond control.

The 12 existing export unit tests pass. The evidence harness also runs
successfully. Focused Clippy with warnings denied, workspace library/binary
Clippy with all features, and workspace formatting pass.

Poppler comparisons use matching 192 DPI raster output and the application SVG
renderer. Mean absolute RGB error on the 0-255 scale falls as follows:

| Fixture                         | Before | After |
| ------------------------------- | -----: | ----: |
| Ethanol, Flat                   |  4.269 | 1.775 |
| Ethanol, Glossy                 | 13.451 | 1.473 |
| Sodium chloride                 |  2.989 | 1.868 |
| Nested/opacity fixture, 96 DPI  | 10.067 | 0.779 |
| Nested/opacity fixture, 144 DPI | 12.882 | 0.779 |

The remaining cross-renderer difference includes antialiasing and color
conversion. The 72 DPI control is unchanged. Page-PDF raster output is
pixel-identical before and after for all four model/2D fixtures, and the
ordinary 2D standalone PDF is byte-identical. Resource-dictionary ordering can
change PDF bytes without changing their rendering.

Run the regressions and generate raw fixtures with:

```sh
cargo test --locked -p reshiki-io --test pdf_gradients
cargo test --locked -p reshiki-io --lib export::tests
RESHIKI_PDF_QA_DIR=/tmp/reshiki-pdf-gradients \
  cargo test --locked -p reshiki-io --test pdf_gradients \
  export_pdf_gradient_evidence -- --ignored --exact
pdftoppm -r 192 -png -singlefile \
  /tmp/reshiki-pdf-gradients/ethanol-flat.pdf \
  /tmp/reshiki-pdf-gradients/ethanol-flat-pdf
```

The ignored harness in
[`crates/io/tests/pdf_gradients.rs`](../../crates/io/tests/pdf_gradients.rs)
writes native documents, SVGs, SVG-rendered PNG references, standalone PDFs,
page PDFs and the transform fixture at three DPIs. Scratch exports are not
committed. This review verifies the common export libraries; it does not claim
a separate native-menu, system-clipboard or browser interaction test.
