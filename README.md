# Moruno

Draw molecules, build reaction schemes, and prepare figures on an editable canvas.

[Download](https://github.com/Ameyanagi/moruno/releases) · [Visual manual](https://ameyanagi.github.io/moruno/guide/first-molecule/) · [Development](https://ameyanagi.github.io/moruno/developer/development/)

[![Moruno's molecular drawing workspace](website/public/manual/workspace.png)](https://ameyanagi.github.io/moruno/)

Start with JACS / ACS styling. Attach templates, refine selected structures, or ask the assistant to propose a drawing. Review edits and undo changes. Copy editable structures or export SVG, PDF, and PNG.

## Install

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then download Moruno for Apple Silicon macOS, Windows (x64 / ARM64), or Linux (x64 / ARM64). The first launch needs internet access to set up local chemistry tools.

[Installation guide](https://ameyanagi.github.io/moruno/guide/install/)

## Contribute

Moruno uses Rust, Iced, and a local Python/RDKit worker. See the [developer guide](https://ameyanagi.github.io/moruno/developer/development/) for setup, checks, and contribution instructions.

Moruno is under active development. [Report a problem](https://github.com/Ameyanagi/moruno/issues).
