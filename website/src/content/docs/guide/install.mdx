## 1. Install uv

Moruno uses **uv** to set up its chemistry tools on your computer. You do not need to install Python separately.

import { Code, Tabs, TabItem } from "@astrojs/starlight/components";

<Tabs>
  <TabItem label="macOS">
    With Homebrew:

    <Code code="brew install uv" lang="sh" />

    Or follow the [uv installer instructions](https://docs.astral.sh/uv/getting-started/installation/).

  </TabItem>
  <TabItem label="Windows">
    In PowerShell:

    <Code code="winget install --id astral-sh.uv -e" lang="powershell" />

  </TabItem>
  <TabItem label="Linux">
    Follow the [uv installer instructions](https://docs.astral.sh/uv/getting-started/installation/).
  </TabItem>

## 2. Download and open

[Choose a download on GitHub Releases](https://github.com/Ameyanagi/moruno/releases).

| Your computer     | Package              | Open after extracting |
| ----------------- | -------------------- | --------------------- |
| Apple Silicon Mac | `macos-arm64.zip`    | `Moruno.app`          |
| Windows x64       | `windows-x64.zip`    | `moruno.exe`          |
| Windows ARM       | `windows-arm64.zip`  | `moruno.exe`          |
| Linux x64         | `linux-x64.tar.gz`   | `moruno`              |
| Linux ARM         | `linux-arm64.tar.gz` | `moruno`              |

Keep the extracted contents together. On Mac, you can move **Moruno.app** to Applications.

Mac requires Apple Silicon and macOS 14+. Windows x64 requires Windows 10/11; Windows ARM requires Windows 11 and uses its built-in x64 emulation for chemistry. Linux builds target Ubuntu 22.04+ on x64 and 24.04+ on ARM. Intel Macs are not supported.
