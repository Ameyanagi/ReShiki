ReShiki 0.6 includes the drawing and chemistry tools. **You do not need to install Python, RDKit, or uv.** There is no chemistry download or environment setup on first launch.

## 1. Download and open

[Choose a download on GitHub Releases](https://github.com/Ameyanagi/ReShiki/releases).

| Your computer     | Download ends in          | Install                                         |
| ----------------- | ------------------------- | ----------------------------------------------- |
| Apple Silicon Mac | `macos-arm64.dmg`         | Open, then drag **ReShiki** to **Applications** |
| Windows x64       | `windows-x64-setup.exe`   | Run setup, then open **ReShiki** from Start     |
| Windows ARM       | `windows-arm64-setup.exe` | Run setup, then open **ReShiki** from Start     |
| Linux x64         | `linux-x64.tar.gz`        | Extract, then run `reshiki`                     |
| Linux ARM         | `linux-arm64.tar.gz`      | Extract, then run `reshiki`                     |

Windows setup installs for your account. Mac downloads are signed and notarized; Windows downloads are unsigned. Portable ZIP downloads are also available. Keep a portable download’s extracted contents together.

Upgrading from Moruno? Open your existing `.reshiki` and `.moruno` drawings normally. Templates, assistant preferences, and recovery drafts are copied on first launch; the originals stay in place. New drawings use `.rsk`.

Mac requires Apple Silicon and macOS 14+. Windows requires Windows 10/11 on x64 or Windows 11 on ARM64. Linux builds target Ubuntu 22.04+ on x64 and 24.04+ on ARM. Intel Macs are not supported.

## 2. Start drawing

New drawings start with a blank canvas. Drawing, imports, molecular properties, and chemistry checks work offline from the first launch. The optional assistant needs a Codex connection and internet access.

## Updates

Click **ReShiki** at the top left → **Check for updates**. ReShiki also checks once a day in the background; turn off **Check automatically** here if you prefer.

<Screenshot
  src="/manual/updates.png"
  alt="ReShiki's update window shows the installed version, a manual check button, downloads, and the automatic-check preference."
/>

When an update is available, choose **Download update**, close ReShiki, and install the new version. Your drawings and settings stay in place. Updates are never installed while you draw.
