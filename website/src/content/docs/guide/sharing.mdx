## Keep an editable original

**Save** writes a `.rsk` file with the complete drawing. If you enter a name without an extension, ReShiki adds `.rsk`, for example `Esterification.rsk`. Use **Save as** for a separate version. Reopen it with **Open**.

The file contains readable JSON text. Existing `.reshiki` and `.moruno` drawings also open normally; **Save** keeps their current filenames. Use **Save as** to save a copy with the shorter `.rsk` extension.

If ReShiki offers a recovery draft after an interrupted session, choose **Restore latest** to inspect it, then save it to a file.

## Choose an export

Open **Export → Figure**, choose PDF, SVG, or PNG, then click **Export**. Expand **Structure & exchange** for molecular formats and CDXML, or **Pages & printing** for page setup and printing. **Editable document** saves the complete `.rsk` original.

PNG uses up to 1200 dpi and automatically lowers resolution for large drawings while preserving physical size. The saved-file status reports the actual pixel dimensions and DPI. If chemistry analysis fails, figure export preserves the visible drawing and shows a review notice instead of blocking Save. [Figure export details and limits](/developer/figure-export/).

File exports use the full drawing. **Copy image** uses the current selection when objects are selected.

| You need                     | Use                                              |
| ---------------------------- | ------------------------------------------------ |
| A vector figure              | **SVG** or **PDF**                               |
| A high-resolution image      | **PNG**                                          |
| Multiple publication pages   | **PDF · all pages**                              |
| An editable chemical drawing | **CDXML**                                        |
| Chemical structure data      | **MOL**, **SMILES**, or **InChI**                |
| Chemical reaction data       | **RXN** or **Reaction SMILES** in Reaction roles |

Export dialogs also add the selected format’s extension when you omit it.

Molecular and reaction data formats do not retain the full figure layout. Keep the `.rsk` original.

SVG/PNG/PDF retain partial ring curves, free atom labels and front-bond emphasis. Editable CDXML/CDX supports the checked [Haworth convention](/developer/haworth-projections/). Other projection emphasis, partial ring curves and free atom labels remain unsupported in editable exchange; turn off **Front bonds** for other projected structures. Cp/Cp\* are expanded for editable exchange because ChemDraw resaves lose nested haptic definitions in collapsed labels. V3000 attachments require one bond per point; variable attachments do not imply a unique molecular formula.

Anonymous dummy/attachment markers are editor handles and are omitted from figures and Office image copies. Explicit text labels remain visible.

## Copy and paste

Select the objects, then **⌘/Ctrl+C** and **⌘/Ctrl+V**. **Cut** and **Duplicate** are also available above the canvas.

On Windows and macOS, Copy offers supported editable drawing data and an image to the receiving app. **Ctrl+Shift+C** / **Shift+⌘+C** copies an image explicitly; **Ctrl+Shift+V** / **Shift+⌘+V** pastes a picture. Editable exchange depends on the receiving app and the objects used.

In Windows desktop Office, normal Copy embeds a ReShiki drawing. Double-click it,
edit in ReShiki and use **Ctrl+S** to update the open Office document. Then save
the Office document. **Copy Image** pastes a static figure. See the
[Windows workflow](/guide/windows/). For editing across Windows and Mac, retain
the `.rsk` original: Mac Office does not support this Windows OLE workflow.

## Print

On macOS, use **⌘P** or **Export → Pages & printing → Print…**. The native print dialog also offers Save as PDF. Use **Print selection** for selected objects.

On Windows, use **Ctrl+P** or **Export → Pages & printing → Print…**. Preview the page layout in ReShiki, then choose a printer, pages and copies in the Windows dialog. Choose **Microsoft Print to PDF** for a PDF file. See the [Windows guide](/guide/windows/).

On Linux, export PDF to print with your usual PDF application.
