# First-use image exercise

`ethanol.png` is an original ReShiki-rendered drawing of ethanol; `ethanol.rsk`
is its independently authored reference graph (C–C–O, two single bonds, neutral,
no specified stereochemistry). Both are contributed under MIT OR Apache-2.0.
No third-party image was copied. The image was rendered with the application's
`assistant_smoke --render` path, using the known native graph, on 2026-10-09.

The reference is loaded locally for comparison. Choosing the exercise only
attaches the image and fills the composer. Send performs the existing Codex
image reconstruction/review workflow. The guided exercise retains the result
for user Apply even if the user's ordinary Assistant preference is Auto apply.
An independently checked reference does not imply the model will reproduce it.
