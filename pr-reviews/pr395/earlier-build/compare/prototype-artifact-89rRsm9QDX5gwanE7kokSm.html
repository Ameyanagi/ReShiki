Switch a structure between 2D and 3D

Select a molecule and switch it to 3D, back to 2D, or show both, from the bar above the selection or the Structure panel on the right. It stays one molecule: the switch only changes how it is drawn. Drag the 3D model to rotate it. Every render is drawn the way ReShiki would export it: shaded vector discs and cylinders, back to front.

One molecule, two drawings

Switching between 2D, 3D and Both never changes the chemistry or atom identities, and each switch is one Undo step. Going back to 2D can restore your drawing or flatten the current 3D view.

Linked to its structure

In Both, edit the 2D structure and the model is marked out of date, with one click to update. It never re-generates a view you arranged without asking. Try Edit the structure.

Exports like the drawing

PNG, SVG and PDF keep it as sharp vector shapes. ChemDraw (CDX) and Office have no 3D object, so they receive it as a picture; the .rsk file keeps it live.
